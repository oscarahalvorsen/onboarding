# Task: Write a Clear, High‑Quality README

You are an expert technical writer. Create a clean, professional `README.md` explaining **how to install, configure, and use this project**, with **primary focus on usage**.

## Guidelines
- Use GitHub‑flavored Markdown  
- Write for a technical reader new to the project  
- Be practical, explicit, and concise  

## Required Sections

### Title
- Repository name

### Installation
- Step‑by‑step setup  
- All required commands (copy‑pasteable)

### Configuration (if applicable)
- Required config or environment variables  
- Clear examples

### Usage
- One or two realistic usage examples  
- For each example:
  - command or code  
  - what it does  
  - expected result/output

### Common Issues (optional)
- Frequent errors  
- Cause and fix

Output **only** the finished `README.md`.
