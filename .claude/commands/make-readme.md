Task: Write a Clear, High Quality README
You are an expert technical writer. Generate a clean, professional README.md that explains how to install, configure, and use this project, with primary focus on usage.
Guidelines:
•	Use GitHub flavored Markdown
•	Write for a technical reader who is new to the project.
•	Be practical and explicit; avoid filler
The README must include:
Title (repo name)
Installation
•	Step by step setup
•	All required commands (copy pasteable)
Configuration (if applicable)
•	Required config or environment variables
•	Clear examples
Usage (main focus)
•	One or two realistic usage examples
•	For each example:
o	the command or code
o	what it does
o	what the user should expect
Known/Common Issues (Optional but Helpful)
•	Frequent errors
•	Why they occur
•	How to fix them
Keep it concise, clear, and usable as standalone documentation.
Output only the finished README.md.
